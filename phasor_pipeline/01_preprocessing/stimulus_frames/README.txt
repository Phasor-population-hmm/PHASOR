Stimulus frames for raster plots

Put image files here with names: stim_c0.png, stim_c50.png, stim_c60.png, etc.
The raster visualization script (raster_sequence_visualization.py) in this folder
looks here by default. No path configuration needed.

If this folder is empty or missing, rasters still run; only the text labels (C-0, C-50, ...) are shown.
